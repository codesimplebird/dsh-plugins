# extras · 可选配置与工具

| 目录/文件 | 用途 |
|---|---|
| `planner-executor/` | agent 预设：主会话 pro 规划 + 子代理 flash 执行 |
| `launcher/` | Windows 一键启停 `dsh web` 的批处理脚本（需要 `dsh-autostart`） |
| `credentials.example.yaml` | 凭据模板（复制到 `%USERPROFILE%\.dsh\.credentials.yaml`） |
| `profile-examples.md` | 可直接粘进 profile `cordis.patch.yml` 的配置片段 |

所有内容都是**示例**，按需取用；不要提交真实密钥。
